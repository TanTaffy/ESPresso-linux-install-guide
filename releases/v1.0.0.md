# ESPresso 1.0.0

ESPresso 1.0 brings five built-in themes and a simple custom theme editor to the FreeRTOS layout and ESP-IDF skeleton workflow.

- Choose **Latte**, **Espresso**, **Midnight**, **Paper** or **Stinger** beside undo/redo. Stinger uses MSM-inspired purple and yellow on dark panels.
- Create a custom theme using five colours: background, panels, text, accent and shared data. Other shades follow automatically, with live preview and a contrast hint.
- Save, edit and delete named custom themes. Appearance persists across restarts and stays separate from layouts and generated firmware.
- Canvas nodes, connections, controls, minimap, code previews, forms and dialogs follow the selected palette.

The release includes the existing task templates, libraries, typed queues and mailboxes, notification and queue-triggered tasks, Config.hpp settings, and project import/export. Imported task files are preserved as whole files, with existing flow and interfaces protected and new connectors clearly marked when they need code integration.

## Download

Use `ESPresso-1.0.0-Windows.exe`; no separate Node.js, Python or compiler installation is needed to run the desktop app. A SHA-256 checksum accompanies the download. The Windows app remains unsigned.

Firmware development uses your normal ESP-IDF environment. This release is Windows only. Automated firmware checks use a host harness; hardware-specific drivers and board testing remain part of firmware development.
