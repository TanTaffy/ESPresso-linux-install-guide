ESPresso 0.7.0 brings reusable task types, richer FreeRTOS data flow and configuration that survives firmware development and project re-import.

### Download

Download **ESPresso-0.7.0-Windows.exe** and run it on Windows x64. This is a portable package containing the desktop app and native backend; it needs no separate Node.js, Python or compiler installation. A SHA-256 checksum is provided alongside it. Source archives are available below.

### Configuration and project round trips

- Every task can add typed settings. Templates prepopulate the same controls.
- The **Config File** page is a read-only overview, with task namespaces generated automatically.
- Task period, priority, stack size and core affinity live in the configuration file and drive the generated FreeRTOS runtime.
- FIFO capacity and send/receive timeouts are also configured there.
- Import restores edited values and C++ expressions into their task, queue and step controls.
- Handwritten configuration, additional source files, assets, CMake customisations and imported library edits survive re-export. Conflicts are reported without overwriting the original content.
- New constants follow the surrounding indentation and line endings, including nested namespaces, tabs and CRLF.

### Task types and libraries

- Create reusable task types with base code, default libraries, settings, descriptions and image icons.
- Manage task types as individual JSON files in Documents/ESPresso/Task templates.
- CAN ships as an ordinary editable task type, and MSM_CAN as an ordinary default library.
- The canvas provides Task, Task from template, Queue and Shared struct actions.
- User-facing catalog folders open correctly from the portable Windows app.

### FreeRTOS and data types

- Typed FIFO queues with timeouts and failure policies.
- Latest-value mailboxes that overwrite unread values.
- Tasks triggered by one queue, several selected queues/mailboxes, or counting notifications.
- Multi-input tasks receive a typed event identifying its source and serve pending inputs in rotation.
- Fixed arrays, nested structs, enums and external/library payload types, with compile-time checks for byte-copy-safe payloads.

### Validation and limits

Validated with native backend tests, compiled generated-C++ host tests and three desktop suites against the packaged application. The ADC → external implementation → import → add GPS → re-export workflow is covered. ESP32 hardware testing remains outstanding.

Configuration import recognises unambiguous scalar const/constexpr declarations. Other C++ is preserved. Keep the CMake and implementation section markers so ESPresso can safely update generated structure. Projects exported by earlier development versions may require a fresh export with this version.
