# ESPresso 1.3.2

Generated task files are easier to read, with concise comments and simpler send calls.

- Keep the task TODOs, implementation notes and short action labels. Remove repeated editing instructions, copied payload definitions and lengthy lifecycle explanations; setup and loop are labelled **Runs once** and **Runs repeatedly**.
- Generate plain calls for mailbox sends and for final FIFO sends when no later steps need to be skipped. Keep failure checks before later operations and whenever **Assert success** is selected.
- Apply the same rules to new connectors on imported tasks. Adding an end connector after a recognised final FIFO send restores its return-on-failure check, preserving **Skip remaining steps** behaviour.

Validated with generated C++ execution tests for full queues, connector ordering, early returns and repeated import/export, plus desktop import/export coverage.

The Windows release includes a portable executable and its SHA-256 checksum.
