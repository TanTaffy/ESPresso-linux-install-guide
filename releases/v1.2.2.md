# ESPresso 1.2.2

The **Task types** page now has a compact saved-type list, clearer selection and a dedicated space to start creating or editing a reusable task.

- Moved folder paths, file-sharing guidance and refresh controls into a collapsible **Task types folder** section.
- Simplified the page copy and task cards, with step counts and compact duplicate/delete actions.
- Added an editor heading with the task type's name and icon, plus a reminder that changes apply to newly added tasks.
- Kept catalog loading errors visible without showing file-management details during everyday editing.

The Windows release includes a portable executable and its SHA-256 checksum.
