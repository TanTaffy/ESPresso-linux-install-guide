# ESPresso 0.8.0

Task exports now use ordinary C++ with no ESPresso section markers. Import preserves whole task source and header files, including formatting and helpers.

- Imported tasks are marked **Imported · Limited editing** on the canvas and in task settings.
- Existing task flow, connectors, C++ names, event interfaces, data definitions and dependencies are protected. Display names, positions and config values remain editable.
- Add new tasks and input/output connectors. Connections on imported tasks show **Requires code update**, with the required includes and calls in the inspector and `connection-updates.md`.
- Pending connection status survives reimport. **Mark code updated** records that you integrated the call in your editor.
- Generated CMake lists live in their own file, keeping custom build files unchanged while new tasks and libraries are registered.
- Shared-object startup lives in generated runtime code so new queues and structs work alongside a preserved `main.cpp`.

This changes the exported project format. Import a fresh export from this version; legacy section-marker projects are not supported.

The Windows portable app is provided with a SHA-256 checksum.
