# ESPresso 1.1.2

Generated task skeletons now explain their payloads and runtime behaviour directly in the code.

- Local payload variables have field summaries showing declared types, defaults, arrays and nested type details. External payloads point to their defining headers.
- Local-copy comments explain that values are initialised on each call and must be explicitly published or sent to share changes.
- Setup and loop comments describe startup, configured periods, queue messages, multi-input events and counting notifications.
- Queue steps identify their Config File timeout setting and explain the selected skip, continue or assert behaviour, including setup failures and mailbox sends.
- Snapshot reads and writes explain whether they copy shared data or publish the complete local value. Queue-triggered events are documented as already received.

Imported task source remains preserved as written.

## Download

Run `ESPresso-1.1.2-Windows.exe` on Windows x64. The portable app includes the native backend and needs no separate Node.js, Python or compiler installation. A SHA-256 checksum accompanies the download.
