# ESPresso 1.3.0

Return to an edited ESPresso project and extend it with new tasks and connectors while keeping your handwritten code.

- Add connectors at the start or end of an imported task's `loop()`. ESPresso generates their transport code on export and preserves the existing implementation, trigger and connections.
- Assign new libraries to imported tasks, including their headers and build dependencies. Existing library source and additional project files are preserved.
- Import an exported project folder, its project manifest, layout file or root `CMakeLists.txt`. Re-import tolerates Windows line endings and UTF-8 BOMs, regenerates missing documentation and editor settings, and excludes build output and Git metadata.
- See clearer guidance in imported-task settings, exported source comments, the README and the export file list about where to edit your code.
- Recover your previous session on launch, save a separate layout with **Save as…** (Ctrl+Shift+S), and use the bug icon to report an issue on GitHub.

Imported tasks have limited functionality: existing flow and data definitions stay protected. Use received values and fill outgoing samples in your editor. Early returns skip connectors placed at the end of the loop.

The Windows release includes a portable executable and its SHA-256 checksum.
