# ESPresso 1.3.1

ESPresso now checks GitHub for updates in the background when the packaged app starts.

- A prompt appears when a newer stable Windows release is available. Choose **Download update** to open the official executable download in your browser, or **Not now** to continue editing.
- The prompt waits until project setup or session recovery is finished. Each launch checks once, and offline connections or GitHub errors stay quiet.
- Updates are downloaded only after you accept. ESPresso keeps your layout open while you download the new version.

The Windows release includes a portable executable and its SHA-256 checksum.
