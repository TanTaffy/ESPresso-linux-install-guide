# ESPresso 1.1.0

Generated task code now uses short payload type names, making setup, loop and queue event declarations easier to read.

- Tasks import the payload types they use with declarations such as `using ::espresso::data::PressureData;` inside their task namespace.
- Generated variables use `PressureData pressure{};` instead of repeating the full namespace.
- Queue-triggered loop parameters and multi-input event wrappers use the same short type names.
- Each required type is imported once per task, including types shared between setup and loop.

Existing imported task files remain preserved as written.

## Download

Run `ESPresso-1.1.0-Windows.exe` on Windows x64. The portable app includes the native backend and needs no separate Node.js, Python or compiler installation. A SHA-256 checksum accompanies the download.
