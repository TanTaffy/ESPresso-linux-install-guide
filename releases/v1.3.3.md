# ESPresso 1.3.3

ESPresso opens directly on the canvas, without the **Start your program** popup.

- Start adding tasks immediately. Set the project name and board whenever needed by clicking the project name in the header to open **Project settings**.
- Creating a new layout or discarding a recovery copy also returns directly to an empty canvas.
- Session recovery and update notifications remain available.

The Windows release includes a portable executable and its SHA-256 checksum.
