# ESPresso 1.2.0

ESPresso now takes fewer steps to get from a new layout to an ESP-IDF project you can build.

- Choose a project name and board up front. Name tasks and data once; ESPresso generates code identifiers and keeps them stable after export.
- Set task timing in milliseconds or Hz, or choose **When [data] arrives** directly. Create connected incoming or outgoing data from a task.
- New nodes are placed in free space. Data names are consistent across the canvas, list and editor, with advanced controls tucked away.
- Use the **Array mode** switch to show extra field controls. Arrays retain an `[8]`-style indicator when those controls are hidden.
- The Libraries page has a compact selection list, collapsible folder/build settings and protection against discarding unsaved library edits.
- Disabled task actions explain their prerequisites, including missing message data or notification targets.
- Export opens on the selected task's code, groups user files, lists unfinished implementation steps and previews the final output path before writing.
- Open exported projects in VS Code, detect installed ESP-IDF SDK files and copy build commands. Workspace compile-command settings survive import/export.
- Generated placeholders use one TODO heading with wrapped instructions beneath it, without a repeated title.
- The pressure example runs the ADC every 100 ms, publishes into a latest-value mailbox, and wakes CAN with the newest unread sample as `event`. Older unread values are replaced instead of building a backlog.
- Stinger is now a light theme with Paper's backgrounds, purple actions and yellow data accents. A small neutral version label sits inline beside the ESPresso logo.
- Fixed ESP-IDF component discovery and the default **Any core** setting. Added a real SDK build check via `npm run test:idf`.

Project imports require the corrected `include("${CMAKE_CURRENT_LIST_DIR}/generated/project.cmake")` line. The old relative include is rejected; no migration or legacy-format support is added.

The Windows release includes a portable executable and its SHA-256 checksum.
