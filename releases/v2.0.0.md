# ESPresso 2.0.0

ESPresso now runs natively on Windows, macOS and Linux.

- Native packages for Windows x64, Intel and Apple Silicon Macs, and Linux x64/ARM64.
- VS Code and ESP-IDF detection on each OS, with the right terminal commands for your system.
- Updates choose the download for your OS and CPU.
- Saving, replacing and importing layouts works in folders with Unicode names.

All five platforms pass the native tests, desktop suite and packaged-app checks. Each download includes a SHA-256 checksum file.
