# ESPresso 1.1.1

Queue operations now use short calls with timeouts read from Config File. Generated skeletons also include a creator credit, with a coffee pun at the top of each new task implementation.

- Generated source and build files credit James Platt and Manchester Stinger Motorsports; JSON exports store the credit as metadata.
- Only `main/tasks/*_task.cpp` files receive puns, selected from twelve coffee lines and kept consistent for each task.
- Imported task files, handwritten configuration and third-party library sources remain preserved as written.
- Imported badges on canvas nodes now align with the title and have more space above and below.
- Generated task code uses short helper calls and `parameters::` timeout settings for easier reading.
- Queue helpers now read their timeouts from each task's namespace in Config File. Task code calls `send_pressure(pressure)` or `receive_pressure()` without timeout arguments, casts or tick conversions.
- Receive helpers return an optional sample, making an empty queue or timeout explicit while preserving the selected failure behaviour.
- Queue controls explain that taking a message removes the oldest waiting item and delivers it to one receiver.

## Download

Run `ESPresso-1.1.1-Windows.exe` on Windows x64. The portable app includes the native backend and needs no separate Node.js, Python or compiler installation. A SHA-256 checksum accompanies the download.
